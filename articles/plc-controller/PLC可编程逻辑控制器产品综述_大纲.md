# PLC 可编程逻辑控制器产品综述 · 大纲

## 〇、一句话定位
- 本质：为工业现场设计的循环扫描执行可编程数字运算系统，替代继电器硬接线逻辑
- 反直觉点：确定性来自扫描周期而非算力 / 梯形图是程序非电路 / 输出响应慢半拍因扫描 / 位数被参考源吃掉 / 余量是工程纪律
- 锚定数字：IEC 61131-3（五种语言）/ IEC 61499 / GB/T 15969 / 扫描 0.1~10 ms/千指令 / 8·16·32 点 / 12·13·16 位 / 24V SELV / IP20·IP65 / -20~60℃ / PROFINET RT 1~4 ms
