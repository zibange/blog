## 〇、一句话定位
- 视频处理器 = 显示系统的信号处理中枢
- 工程端的五个必算项：屏体点数、输入路数、开窗与叠加、延迟与同步、冗余等级
- 全文说明参数口径（行业通用基准 / 工程估算）

## 一、产品设计方案
- 1.1 系统定位与整体架构（五层：信号源 → 处理器 → 发送分发 → 显示终端 → 管控运维）
  - 图1 分层架构
  - 四条工程实施要点（单点核心、带载定台数、输入≠开窗、延迟与同步是隐蔽指标）
- 1.2 产品形态分类（LED 专用处理器 / 纯处理器 / 拼接处理器 / 多画面分割器 / 分布式坐席 / 播控一体机）
- 1.3 设计要点与工程约束
  - 带载与拼接域（单口 / 单机 / 拼接域三层口径）
  - 输入接口匹配（EDID 失败、长距 HDMI 衰减、HDCP 黑屏）
  - 同步与帧率一致性（Genlock / 帧锁相 / FRC）
  - 冗余与可用性（主备、双链路、双电源、UPS）
  - 散热与机房环境、布线与预留

## 三、技术原理
- 3.1 信号链路总览（图3 十二环节三段划分，端到端延迟 2~4 帧）
- 3.2 接入段：接口与通道编码、EDID 三种策略、色空间与量化范围
- 3.3 处理段：缩放算法五档对照、去隔行三策略、降噪与锐化的平衡
- 3.4 画质段：HDR 映射三策略、Gamma 与低灰、逐点校正原理与工程关注点
- 3.5 输出段：帧同步三机制、刷新率三档与拍摄兼容、位深抖动、数据重组与打包
