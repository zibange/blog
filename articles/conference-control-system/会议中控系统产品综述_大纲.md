会议中控系统产品综述：把十几个遥控器的逻辑，收进一块主机的时序里
  - 〇、一句话定位
    - 反直觉点一：中控最难的是时序而非能不能控
    - 反直觉点二：串口数量比能控多少设备更致命
    - 反直觉点三：红外学习不是录下来就行
    - 反直觉点四：继电器触点容量决定能否带电控强电
    - 十个锚定数字
  - 一、产品设计方案
    - 1.1 系统形态：主机 + 控制网络 + 触摸屏 + 受控设备（三种部署形态）
    - 1.2 控制接口面貌：RS-232/485、IR、继电器/干接点、I/O、TCP/IP
    - 1.3 与相邻系统的边界：矩阵 / BAS / 会议系统
    - 1.4 常被忽视的合规前提：消防强切（GB 50314 4.7）
    - 1.5 中控的「灵魂」在工程文件，不在硬件
