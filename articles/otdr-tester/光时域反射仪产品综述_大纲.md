# 光时域反射仪（OTDR）产品综述 — 大纲

## 〇 一句话定位
- OTDR = 光缆链路的 X 光机：单端注入窄光脉冲，靠瑞利背向散射 + 菲涅尔反射回波绘出「功率—距离」曲线，读出衰减、事件损耗、连接器位置、宏弯与断点。
- 差异化分工：BOTDA 测分布应变 / FBG 解调仪读光栅波长 / **OTDR 测光纤链路本身健康**。

## 一、产品设计方案
- 1.1 内部四块：发射（脉冲激光+调制）/ 收发隔离与接收（环形器+APD）/ 采样处理（ADC+平均+事件分析）/ 人机接口（SOR 报告）
- 1.2 三种形态：手持现场型 / 台式实验室型 / 在线监测模块式（选型按链路长度与事件密度）
- 1.3 测量信号链路：发射→注入→回波→APD→ADC→平均→dB→事件表

## 二、核心参数与选型
- 2.1 参数清单：波长/动态范围/盲区/脉宽/距离精度/采样分辨率/折射率/平均时间
- 2.2 十四个原创工程算例（标号贯穿正文）
  1. 时域测距 $z=ct/(2n_g)$
  2. 采样分辨 $\Delta z=c\Delta t/(2n_g)$
  3. 脉宽盲区 $D=cw/(2n_g)$（核心权衡）
  4. 动态范围→测距 $L=(D-M)/\alpha$
  5. 衰减系数=曲线斜率
  6. 熔接损耗（四点法）
  7. 菲涅尔反射与回波损耗
  8. 宏弯识别（双波长对比）
  9. 平均次数→动态范围
  10. 测量时间预算
  11. 折射率误差→定位偏差
  12. 链路总损耗对账
  13. 事件搜索阈值
  14. 单端假增益→双端测试

## 三、技术原理
- 3.1 瑞利背向散射→衰减测量
- 3.2 菲涅尔反射→三类事件（非反射/反射/终点）
- 3.3 距离定位与折射率（两大陷阱：盲区、假增益）
- 3.4 动态范围/盲区/脉宽三角权衡
