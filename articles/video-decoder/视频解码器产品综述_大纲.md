## 〇、一句话定位

**把网络上那些压缩过的码流，实时还原成一块大屏能点对点点亮的画面。**

- 反直觉点：买的不是「路数」，是**像素吞吐率**；路数只是它在某个分辨率下的一个切片
- 六个锚定数字：
  1. 1080P@30 = 62.2 Mpx/s（定义为 1 个解码当量）
  2. 4K@30 = 248.8 Mpx/s = **4.0 当量**；4K@60 = **8.0 当量**
  3. 1080p60 像素时钟 148.5 MHz → TMDS 4.455 Gbps；4K60 = 594 MHz → **17.82 Gbps**（HDMI 2.0 上限 18）
  4. 链路速率 = 像素时钟 × 每像素传输比特数 × 10/8
  5. 25 fps、GOP=50 帧 → **起播最长等 2 s**（上墙黑屏的真因）
  6. GB 50395-2007 6.0.9：观看距离 = 屏幕对角线 4~6 倍；5.0.4-4：联动响应 ≤4 s

## 一、产品设计方案

### 1.1 架构：从码流到像素的七段链路
取流与信令（GB/T 28181 / RTSP / ONVIF）→ 解封装（RTP/PS/TS）→ 硬解码 → 图像后处理（去隔行/缩放/OSD）→ 拼控与开窗 → 输出编码（HDMI/DP/SDI）→ 显示终端
- 配图 1：arch-pipeline.png

### 1.2 形态谱系：四个正交维度
- 维度一 部署形态：机架式一体 / 盒式单路 / 板卡插箱 / 分布式节点
- 维度二 输出接口：HDMI 2.0 / DP 1.4 / 12G-SDI / DVI / IP 化输出
- 维度三 解码方式：硬解 ASIC / SoC 固定管线 vs 软解 CPU
- 维度四 拼控深度：纯解码 vs 解码+拼控一体（开窗/漫游/预案）

### 1.3 九道设计关

## 二、核心参数与选型（六笔账）

### 2.1 参数速查表

### 2.2 第一笔账：解码能力的真实单位是像素/秒
- $P=\sum N_i W_i H_i f_i$；1080P@30 = 62.2 Mpx/s ≡ 1 当量
- 换算表（D1 / 720P / 1080P / 4MP / 4K × 25/30/60 fps）
- 标称 32 路 1080P@30 → 4K@30 只有 8 路，4K@60 只有 4 路
- 配图 2：throughput-budget.png

### 2.3 第二笔账：输出口带宽，4K60 为什么贴着 HDMI 2.0 的天花板
- 像素时钟 = $H_{tot}\times V_{tot}\times f$（1080p60 = 2200×1125×60 = 148.5 MHz）
- 链路速率 = 像素时钟 × 每像素比特数 × 10/8（8b/10b 开销）
- 4K60 8bit → 17.82 / 18 Gbps（余量 1%）；10bit 4:4:4 → 22.3 Gbps ✗；4:2:2 → 14.85 ✓
- DP 1.4 HBR3 有效 25.92 Gbps 的对照价值
- 推论：监控上墙 8 bit 足够；4K60 已贴顶，线材质量直接决定能否点亮

### 2.4 第三笔账：拼接墙的逻辑分辨率决定要几个输出口
- 3×3 的 55" 1080P 单元 → 5760×3240 = 1865 万像素 @60 = 1119.7 Mpx/s
- 单 HDMI 2.0 口上限 497.7 Mpx/s（4K60）→ 至少 3 个口
- 点对点 vs 拉伸；拼缝与可视像素损失

### 2.5 第四笔账：码流带宽与并发
- 码率表（H.265 / H.264 工程基准）；H.265 省 40~50%
- 瓶颈是**并发连接数与转发能力**，不是总带宽
- 主/子码流切换与轮巡

### 2.6 第五笔账：端到端延迟预算
- 六段分解：网络 / jitter buffer / 解码 / 后处理 / 合成 / 屏体
- 典型 250~750 ms；电视的 MEMC 加 50~100 ms（必须关）
- 云台控制是往返：2×T + 机械响应

### 2.7 第六笔账：功耗、噪声与机房
- 满配 4K 解码机架式 200~500 W；1U

## 三、技术原理

### 3.1 码流怎么变回像素，以及 GOP 那笔账
- 帧内/帧间预测、变换量化、熵编码；参考帧缓存 → **内存带宽才是硬解核的真实约束**
- **起播 = 等到下一个 IDR**；$T_{first}\le t_{GOP}$，25 fps / GOP=50 → 2 s
- 配图 3：latency-gop.png

### 3.2 硬解 vs 软解：为什么监控一定是硬解
- 固定管线不可升级；4K 路数是硅片定死的
- 软解 1080P@30 约占 1 核 30~60%

### 3.3 缩放与拼接：像素不能随便拉伸
- 非整数倍放大 → 文字发虚；开窗数量 = 解码通道 + 合成图层
- LCD 拼缝 3.5 / 1.7 / 0.88 mm；拼缝不显示像素

### 3.4 色度采样与位深：4:2:0 上墙为什么边缘发糊
- 4:2:0 色度减半；10 bit 源 → 8 bit 输出灰阶断层
- 与 2.3 的接口带宽联动

## 六、实际案例与设计方案（三个，均标注工程估算）
