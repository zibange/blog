# BACnet 楼宇控制器产品综述 — 大纲

## 〇 一句话定位
- 本质：遵循楼宇自控国际互操作标准（ASHRAE 135 / ISO 16484-5 / GB/T 28847.5）的控制器，把不同厂商的空调与机电设备抽象成统一的标准对象与服务，在同一平台对话。
- 买的是「不同厂家设备能互相听懂、长期不被单一厂商锁死」的互操作能力：对象建模规范性、BIBB/PICS 覆盖度、优先级仲裁、令牌实时性、跨子网发现、COV 流量优化、安全隔离。
- 差异化分工：本系列 control 类《PLC》管机器怎么动（工业逻辑）、《KNX》管灯和帘怎么调（末端场景）、本篇 BACnet 管不同厂家的空调机电怎么在同一张图里对话（互操作）。
- 四个反直觉点：①两个都贴「支持 BACnet」的设备不保证互操作（看 PICS/BIBB/BTL）②「点不动」多半是高优先级写没释放，不是控制器坏③传统 BACnet/IP 无认证无加密，开放=不设防④COV 省流量但拿状态管理换，不是越多越好。
- 锚定数字：ASHRAE 135（1995 ANSI）、ISO 16484-5（2012）、GB/T 28847.5-2021（2021 第3号公告、TC426 归口、非等效采用 ISO 16484-5:2012）、GB 50314-2015、GB 50348-2018、GB/T 22239-2019、BTL/BIBB/PICS、B-BC/B-AAC/B-ASC、BACnet/IP UDP 47808(0xBAC0)、MS/TP 9600~115200、BACnet/SC(TLS)。厂商口径标注「未独立复现」。

## 一、产品设计方案
- 1.1 三级网络（IP 管理层/路由集成层/MS/TP 现场层）+ 四类角色对象（B-BC/B-AAC/B-ASC/B-OWS）+ 统一对象模型
- 1.2 三种形态：全 BACnet 原生 / IP 骨干+MS/TP 现场（主流）/ 混合网关集成
- 1.3 一次「读温度并启风机」六动作：发现→建模→读取→订阅→写入→释放

## 二、核心参数与选型
- 2.1 参数清单（工程基准）：标准符合/数据链路/设备对象类型/实例号/MS-TP波特率/节点/优先级/COV/点数/一致性/安全/趋势报警
- 2.2 十四个原创工程算例（标号贯穿正文）
  1. 设备实例号 22 bit 编码 $N=2^{22}$=4,194,304，8+6+8 分段，重复才是灾难
  2. 一台 AHU 点数核算（AI8+AO4+BI5+BO3=20，含内部约 25~35 点），40 台≈1000 点
  3. MS/TP 令牌一轮 $T=N(t_{turn}+t_{frame})$，32 站@38400≈0.66s（轮询周期下限）
  4. 波特率 vs 帧时间 $t=L·10/R$，256B：9600→267ms / 38400→66.7ms / 115200→22.2ms
  5. RS-485 段长/节点/终端：38400 建议 ≤900m、32 节点/段、两端 120Ω、单点偏置
  6. COV vs 轮询节约率 $\eta=1-f_{cov}/f_{poll}$，60s vs 1s≈98%（核心）
  7. COV lifetime 续订流量 $r=N_{sub}/t_{renew}$，1000 点/150s≈4.3kbps
  8. 优先级 16 级仲裁 ★ $v_{active}=v_{\arg\min\{p|v_p\neq NULL\}}$，8 级开压过 16 级关，NULL 释放
  9. 优先级残留卡点 $L=N·r·p·W/7$，200 点约 32 个遗留（验收必查）
  10. BBMD 广播放大 $N_{bc}=M^2$，10 子网→100 份，BDT 上限 128
  11. 趋势日志容量 $C=n·86400/T·365·s$，500 点@5min≈840MB/年（本地只留缓冲）
  12. 报警风暴+死区 $r_{eff}=r_{raw}(1-\eta)$，死区0.5℃+延时10s 抑制 80% 误报
  13. BACnet/SC 加密开销 vs 无认证风险：50 台任意可写 / TLS +58% 报文
  14. BIBB/PICS 覆盖率 ★ 11/15=73%，木桶效应取交集，写进合同

## 三、技术原理
- 3.1 对象建模：设备拆成带语义的「对象+属性」（AI/AO/AV/BI/BO/BV/MV/Schedule/Trend Log），vs Modbus 裸寄存器
- 3.2 服务交互：读/写/订阅/发现四类动词（ReadProperty/WriteProperty/SubscribeCOV/Who-Is）
- 3.3 数据链路：IP(47808+BBMD)/MS/TP(令牌)/SC(TLS+WebSocket) 三层分工
- 3.4 优先级数组与命令仲裁：16 槽、写 NULL 释放、Relinquish_Default
- 3.5 一致性互操作三件套：BIBB + PICS + BTL（ASHRAE 135.1）

## 七、市场背景与竞争格局
- 三类玩家：国际楼控大厂 / 国产楼控自动化 / 网关集成商
- 竞争焦点：互操作深度(BIBB/BTL) / 安全(SC) / 开放利旧 / 工程效率(COV)
- 选型问的不是「支持 BACnet 吗」而是「PICS 覆盖哪些 BIBB、有无 BTL、实测能否对上」

## 八、商业模式与趋势
- 预算结构：控制器35-45% / 软件平台15-20% / 传感器执行器15-20% / 网关集成10-15% / 布线施工10-15% / 运维5%
