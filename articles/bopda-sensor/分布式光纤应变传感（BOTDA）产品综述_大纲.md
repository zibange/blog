## 〇、一句话定位

**把一根几十公里长的光缆，变成沿程连续、以米为单位采样、每米一个「应变 + 温度」测点的传感神经。**

- 反直觉点：买的不是仪器，是「长度 × 空间分辨率」的测量容量
- 六个锚定数字：
  1. ν_B0 ≈ 10.8~11.2 GHz（1550 nm SMF 室温）
  2. C_ε ≈ 0.05 MHz/µε
  3. C_T ≈ 1.2 MHz/℃
  4. 1 MHz / 10.8 GHz ≈ 9.3×10⁻⁵（万分之一）
  5. **24 µε/℃**（温度解耦误差的假应变）vs 混凝土真实热应变 10 µε/℃
  6. τ[ns] ≈ 9.8 × Δz[m]（1 m 分辨率 ≈ 10 ns 脉宽）

## 一、产品设计方案

### 1.1 架构：国标把世界分成「单端型」和「环路型」
- GB/T 43256-2023 术语：单端型（脉冲入射端 = 散射光接收端）→ BOTDR；环路型（不同端）→ BOTDA
- 七段链路：光源与频率受控 → 双向光路与偏振管理 → 受激放大与拍频接收 → 时域采样 → 逐频合成布里渊谱 → 物理量反演与解耦 → 标定与分级预警
- 时窗 t_win = 2nL/c ≈ 9.8 µs/km；系数 2 的来源（相遇点以半速前移）
- 配图 1：arch-loop.png

### 1.2 形态谱系：三个正交维度
- 维度一 散射机理与光路拓扑（BOTDR / BOTDA / OFDR / FBG 四路对比）
- 维度二 传感光缆（松套管通信缆不能测应变；紧套 / 金属基 / 定点 / 复合）
- 维度三 光开关与通道复用（总周期 = 通道数 × 单通道时长）

### 1.3 九道设计关

## 二、核心参数与选型（五笔账）

### 2.1 参数速查表（含 GB/T 43256-2023 的测试条件与「动态范围」定义辨析）

### 2.2 第一笔账：空间分辨率与应变精度是一对孪生指标
- Δz = v_g τ / 2 = cτ/(2n) → τ[ns] ≈ 9.8 Δz[m]
- 脉冲谱宽 Δν_pulse ≈ 0.886/τ，BGS 自然线宽 ≈ 30 MHz
- 有效增益比例 η = 1/√(1+(Δν_pulse/Δν_BGS)²)
- 归一化 SNR 因子 η·τ：50 ns 基准 → 10 ns 掉 13.4 倍 → 2 ns 掉 319 倍
- 推论：1 m 分辨率要维持同等精度，测量时间约 ×180（**物理约束，非算法问题**）
- 缓和因素：DPP-BOTDA / PPP-BOTDA / 脉冲编码——三角形面积近似恒定
- 配图 2：tradeoff-res.png

### 2.3 第二笔账：单次测量时长 = 距离 × 频点 × 平均次数
- T = N_freq × N_avg × 2nL/c；30 km 约 60 s，80 km 约 160 s
- 四条结论：与距离线性相关 / 测不了振动（DAS 的活） / 多通道轮巡线性放大周期 / 分区优于堆平均

### 2.4 第三笔账：所有精度目标归结为「在 10.8 GHz 上分辨多少 MHz」
- ±20 µε ↔ ±1.0 MHz；±2 µε ↔ ±0.1 MHz；±0.5 ℃ ↔ ±0.6 MHz
- ±2 µε 与 ±0.5 ℃ 同量级难度；±20 µε 与 ±1 ℃ 几乎等价

### 2.5 第四笔账：链路预算与「环路型」的运维代价
- 30 km 损耗预算表（光纤 6.6 + 熔接 0.45 + 连接器 1.2 + 余量 3.0 ≈ 11.25 dB）
- 环路型单点失效：物理环回 / 冗余芯 / 降级 BOTDR

### 2.6 第五笔账：一天产生多少数据
- 30 km @ 0.1 m 采样 → 30 万点/次 → 3.6 MB/次 → 518 MB/天 → 约 189 GB/年；8 通道约 1.5 TB/年
- 结论：边缘断面归并 + 原始降频归档；基线比单点值重要；采样密度不必追高

## 三、技术原理

### 3.1 物理基础
- ν_B = 2nV_a/λ_p；代入 n=1.468、V_a=5945 m/s、λ=1550 nm → 11.26 GHz
- 三个变量都是 ε 与 T 的函数 → 每批缆必须重新标定

### 3.2 一条自洽的推导链（原创）
- V_a = √[(1−k)E / ((1+k)(1−2k)ρ)]
- ν_B(T₀,ε) ≈ ν_B(T₀,0)(1 + 4.48Δε) → 换算 **0.050 MHz/µε**
- ν_B(T,0) ≈ ν_B(T₀,0)[1 + 1.18×10⁻⁴ΔT] → 换算 1.33 MHz/℃（基准取 10.2 GHz 时为 1.20）
- 结论：两个系数是理论量而非经验值；实测偏离过大应先怀疑光纤型号

### 3.3 BOTDA 与 BOTDR：受激放大带来的量级差
- 自发散射 vs 主动激发相干声波（信噪比差 1~2 个数量级）
- 对比表 + 「断纤后表现」

### 3.4 交叉敏感：一个方程两个未知数，以及那笔 24 µε/℃ 的账（本篇核心）
- 主方程 Δν_B = C_εΔε + C_TΔT，无额外信息则无解
- 双缆法：A 缆（粘结）+ B 缆（松弛测温）
- **Δε_false = (C_T/C_ε)·ΔT_err = 24 µε/℃**
- 混凝土真实热应变 10 µε/℃，假/真 ≈ 2.4:1
- 要把假应变压到真实信号的 1/2 以内 → ΔT_err ≤ 0.2 ℃
- 正向要求：±20 µε 精度 ↔ 允许 0.83 ℃
- 五条工程落地清单（测温缆必须真自由 / 同位置 / 分段基准 / 四季基线 / 时间差分）
- 配图 3：dual-cable.png

### 3.5 空间平均效应：把「裂缝宽度」和「应变阈值」连起来
- ε_avg = w / Δz；裂缝宽度 × 空间分辨率 换算表
- 1 m 分辨率下 0.1 mm 裂缝 ≈ 100 µε；0.05 mm 需缩到 0.2 m 窗口（但信号掉 300 倍）
- 澄清：BOTDA 不测裂缝宽度，测的是窗口内平均应变
- 预警值来源：GB 50982-2014 第 3.4.5 条（从结构分析来，不是从设备说明书来）

## 六、实际案例与设计方案（三个，均标注工程估算）

### 6.1 案例一：长输天然气管道 48 km
- 配置核算表（分辨率档 / 时窗 470 µs / 单次 96 s / 轮巡 3.2 min / 链路 ≈15.5 dB / 桩号误差 ≤1 m）
- 三段判别逻辑：第三方破坏 100~500 µε / 泄漏降温 2~10 ℃ / 土体移动看趋势

### 6.2 案例二：三跨预应力混凝土连续箱梁（70+120+70 m）
- 传感 0.8 km → 时窗 7.8 µs → 单次 1.6 s → **准实时 1~5 分钟/次**
- **温度梯度那笔账**：顶底板温差 15 ℃ → 假应变约 360 µε > 混凝土开裂应变 100~150 µε
- 硬性要求：双缆 + 0.2 ℃ + 四季基线

### 6.3 案例三：城市地下综合管廊 6.2 km
- 变形缝跨接标距设计：L_s ≥ Δmax/ε_allow = 20 mm / 0.01 = **2.0 m**，工程取 2.5 m
- 沉降反演：ε = 4Hδ/L²；20 m 标距内 1 mm → 30 µε，可分辨约 1 mm
- 火灾温度：±0.5 ℃ / 1 m，阈值 60~70 ℃
- 一套光缆同时做变形、沉降、火灾
