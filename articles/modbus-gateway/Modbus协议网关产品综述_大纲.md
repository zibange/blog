# Modbus 协议网关产品综述 · 大纲

## 〇、一句话定位
- 本质：串口（RS-485）→ 以太网/MQTT/OPC UA/BACnet 的协议翻译桥
- 反直觉点：不加速总线只换接口 / 无自动发现靠点表 / 32-bit 浮点 4 种字节序 / 节点 32 硬上限
- 锚定数字：9600/19200/38400、11 位/字节、地址 1–247、功能码 01–16、4x 40001、端口 502、节点 32、距离 1200 m、t_{3.5}、CRC-16 0x8005

## 一、产品设计方案
- 1.1 系统形态：南向串口 + 转换引擎 + 北向网络（图1）
- 1.2 拓扑约束：节点/距离/终端电阻 120 Ω/主从
- 1.3 边界：与 PLC（谁是 master）/ SCADA-BAS（跨协议）/ KNX（协议不重叠）
- 1.4 合规：GB/T 19582、EIA/TIA-485、屏蔽单点接地
- 1.5 灵魂在点表
