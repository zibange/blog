# 分布式可视化坐席节点产品综述 — 大纲

## 〇 一句话定位
- 本质：把远端主机的视频、音频、键鼠信号打包上 IP 网，实现跨楼层/跨机房的一人多机、一机多屏、坐席协作与信号推送——桌面交互层的「网络化的 KVM 矩阵」。
- 买的是「人在坐席、机在机房」的操控与协同能力：并发稳定性、端到端延时、画质（4:4:4）、分级权限、去中心化、开放互通。
- 差异化分工：本系列 display 类《视频处理器/大屏拼控》管的是「上墙显示」，video 类《IPC/NVR/存储》管的是「前端取像与留存」，本篇 control 类坐席管的是「桌面操控与协作」——把人接到机器上，不是把画面接到墙上。
- 三个反直觉点：①延时看的不是平均值而是确定性（抖动比数值更折磨人）②真正难的不是编码而是权限矩阵与「共享谁抢占」③去中心化 ≠ 没有中心，管理软件挂了信号要能继续切。
- 锚定数字：GB 50348-2018、GB 50174-2017、GB 50343-2012、GB/T 28181-2022、GB/T 22239-2019（等保 2.0 三级）、GB/T 9254.1、SJ/T 11141、GB/T 20988-2025（RTO/RPO）、ONVIF Profile S/T/G、H.265/H.264、JPEG2000、SMPTE ST 2110/2059（广电级）、IEEE 1588 PTPv2。厂商口径（≤80 ms 图像 / ≤60 ms KVM / 17~25 ms 视频）均标注「厂商公布、未独立复现、须统一测法」。

## 二、核心参数与选型
- 2.1 参数清单（工程基准）：编码格式/分辨率帧率/色度采样/端到端延时/切换时延/并发路数/一人多机数/权限模型/冗余/传输距离/供电/协议开放
- 2.2 十四个原创工程算例（标号贯穿正文）
  1. 未压缩 4K 裸流 $B=W·H·bpp·f$（4K60 4:4:4 ≈ 11.9 Gbps）→ 压缩必要性
  2. 并发带宽预算 $B_{total}=N_{src}·B_{路}$（40 路 ×0.6 Gbps=24 Gbps，端口留 30% 余量）
  3. 组播 vs 单播放大 $B_{uni}=K·B$ / $B_{mc}=B$（K=10 省 90% 上联）
  4. 端到端延时分解 $t=t_{cap}+t_{enc}+t_{net}+t_{dec}+t_{disp}$（厂商 17~25 ms 视频、KVM ≤60 ms）
  5. 帧缓冲量化 $t_{buf}=1/f$（60fps 16.7 ms vs 30fps 33.3 ms，高帧率反而降延时，反直觉）
  6. 色度采样带宽与画质 $B_{4:2:0}=\frac12 B_{4:4:4}$（细线/文字场景必须 4:4:4）
  7. 键鼠回路 RTT $t_{rtt}=t_{去}+t_{主机}+t_{回}$（≤50 ms 跨屏，拖拽感来源）
  8. 延时确定性：抖动 σ 与 P99（FPGA 固定路径 vs 通用 CPU 调度，验收看 P99 不看均值）
  9. 一人多机漫游边界 $\lceil N/17\rceil$（一套键鼠 ≤17 台厂商口径，分组或加坐席）
  10. 权限矩阵规模 $M=R·S·A$（6 角色×40 主机×4 动作=960 条，按模板下发 + 抢占会签）
  11. PoE 功率预算 $P=N·P_{node}$（24×10 W=240 W < 802.3at 370 W，单根 Cat5e 供电+数据）
  12. 链路冗余切换与 RTO（双网口主备，对照 GB/T 20988-2025）
  13. 操作日志留存 $C=日志量·天数$（等保三级 180 天 ≈ 2.9 GB 文本 + 视频另算）
  14. SM4 国密加密开销（硬件近零 / 软件每核 Gbps 级，涉密必选）

## 三、技术原理
- 3.1 编解码管线：采集→色度采样→帧内/帧间压缩→打包→网络→解码→显示
- 3.2 键鼠注入与 USB 重定向（HID 透传、虚拟 USB、跨屏漫游）
- 3.3 组播分发与 QoS（IGMP Snooping、DSCP、PTPv2 同步）
- 3.4 去中心化转发与管理面分离（节点本地转发，管理软件只做调度）
- 3.5 分级权限与抢占语义（Exclusive/Share/Private/View only）+ 等保审计

## 七、市场背景与竞争格局
- 三类玩家：专业 AV over IP 厂商、安防/指挥融合厂商、IT/服务器厂商
- 竞争焦点：延时确定性 / 协议开放度（互联互通规范）/ 权限粒度 / 国产化与国密
- 私有协议锁定的真实成本（改造 15%~30% 额外施工费，厂商公开口径）

## 八、商业模式与趋势
- 预算结构：节点 45-55% / 交换机网络 15-20% / 软件平台 15-20% / 大屏及配套 10-15% / 运维 5-10%
- SLA：延时 P99 验收 / 7×24 / 备件 ≥5% / 主备切换无感 / 日志 180 天
- 趋势：H.265+JPEG2000 双编码 / 开放互通 / 国产化国密 / AV over IT 融合
