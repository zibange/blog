# 视频存储服务器产品综述 — 大纲

## 〇 一句话定位
- 视频存储服务器 = 机架式服务器 + 磁盘阵列/分布式资源池，承载大规模、高并发、长时间视频码流写入与检索回放的后端存储。
- 买的是「在指定路数与留存天数下，用可运维冗余把每路录像安全存住」的能力。
- 差异化分工：NVR 讲中小规模接入存储一体机 / VMS 讲平台软件 / IPC 讲前端取像 / **本篇只讲集中存储服务器本体**：容量、冗余、带宽、可运维性。

## 二、核心参数与选型
- 2.1 参数清单：盘位容量/硬盘类型/冗余方式/网口/接入路数/心跳/带宽精度/协议/安全/电源
- 2.2 十四个原创工程算例（标号贯穿正文）
  1. 容量折算 $\eta_{\mathrm{RAID6}}=(n-2)/n$，$\eta_{\mathrm{EC}}=N/(N+M)$
  2. 存储量 $C=BT/8$（千路月存约 1.15 PiB）
  3. 写入带宽 $B_{\Sigma}=N_{\mathrm{ch}}B_{\mathrm{ch}}$（千路 4 Gbps）
  4. 顺序写 IOPS $IOPS=B_{\Sigma}/S_{\mathrm{blk}}$（瓶颈非 IOPS）
  5. 随机读分层（热数据上 SSD）
  6. 重构时间 $t=C_d/v_{\mathrm{read}}$（8 TB 约 22 h）
  7. 双盘故障率 $P_2\approx C_n^2 p^2$
  8. 故障发现 $t\le3t_{\mathrm{hb}}$
  9. 带宽验收 $B_{\mathrm{meas}}\ge0.95B_{\mathrm{nom}}$
  10. 分层成本 $C=\sum f_i p_i$
  11. 扩容迁移 $t=V_{\mathrm{mig}}/v_{\mathrm{ded}}$
  12. 对象化 $N_{\mathrm{obj}}=N_{\mathrm{ch}}t_{\mathrm{day}}/t_{\mathrm{seg}}$
  13. 加密开销 $c_{\mathrm{core}}=B/800$
  14. 检索定位（SSD 常驻索引）

## 三、技术原理
- 3.1 RAID 与纠删码：利用率背后的容错哲学（RAID6 利用率高但大项目选 EC）
- 3.2 直存与流媒体转发：省掉哪一段带宽
- 3.3 资源池与统一命名空间
- 3.4 冷热分层与数据生命周期（锁定录像提升容错级别）

## 技术锚点（本轮实查确认）
- **GA/T 2019-2023**《公安视频监控视频存储技术要求》（2023-02-23 发布 / 2023-08-01 实施）：注册类型码 210（媒体存储服务器）；流媒体转发 + 直存双模式；心跳间隔 ≤60 s；带宽负误差 <5%（5.4）；并发写测试持续 2 h（6.5.1）；N+M 纠删码 + 资源池；锁定录像可提升容错级别（4+1→8+2→12+3）；工作温度 0~40 ℃；EMC 满足 GB/T 9254.1-2021 A 类。
- **GB 50395-2007** 5.0.7：视频存储容量和记录/回放带宽与检索能力应满足管理要求（未规定统一留存天数）；6.0.7：宜选用数字录像设备、宜具备防篡改功能。
- **地方《公共安全视频监控系统建设技术规范》** 7.3.2 集中存储设备：标准机架式、冗余热插拔电源、≥2×1000 Mbps RJ45 且支持端口捆绑、RAID 0/1/5/10、支持 GB/T 28181、SNMP、线性扩容、N+M 备份、故障自动切换；7.3.3 云存储：集群管理、动态扩容、节点级容错、无单点故障。
- **GB 50174-2017**《数据中心设计规范》：A 级容错（2N，可用性 99.99%）、B 级冗余（N+1）、C 级基本。
- 容错概率模型：单盘 AFR 2%、MTTR 24 h，36 盘窗口内单盘故障概率 p≈5.5e-5，双盘同故障 P≈1.9e-6/年。
