## 〇 一句话定位
- 一句话定位：宽温、冗余电源、环网自愈的现场网络骨干
- 与 network 同类分工：本篇只写承载本体（IPC 取像 / 存储服务器 / 坐席节点之外）
- 四个反直觉点：
  1. 支持 ERPS/MRP 标签 ≠ 能跨厂商组环（私有环与标准环混跑打架）
  2. 50 ms 是协议倒换 ≠ 业务恢复（MAC/ARP 表老化 300 s）
  3. 宽温/冗余电源/MTBF 5 万小时是纸面参数（10 ℃ 法则退化）
  4. 线速要看 64 B 小包（背板带宽能信、吞吐难测）
- 锚定数字：GB/T 30094-2013、DL/T 1241-2024、IEC 62439-2/-3、G.8032、IEEE 802.x、1588v2、IEC 61850-3/IEEE 1613、EN 50155:2021、GB/T 17626
