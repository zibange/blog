## 〇、一句话定位（北极星）

公共广播系统集业务广播、背景音与消防应急广播于一体，是建筑内信息传递与紧急疏散的重要基础设施。它把多音源、多分区、多优先级的音频信号，通过「音源输入 → 矩阵路由 → 功率放大 → 分区输出」的链路，精确送达每一个需要发声的角落，并在消防等紧急场景下强制切换最高优先级，是弱电系统中「平时服务、急时应急」的典型代表。

## 一、产品设计方案

### 1.1 系统整体架构（三层）
- 音源 / 输入层：麦克风、CD/MP3 播放器、消防联动信号、电话寻呼、广播管理软件
- 主机 / 控制处理层：前置放大器、数字音频矩阵、功率放大器、系统控制器
- 分区 / 终端输出层：吸顶喇叭、壁挂音箱、草坪音箱、号角扬声器、寻呼话筒
- 配图：图1 公共广播系统整体架构

### 1.2 典型形态分类
- 定压式（100V/70V）vs 定阻式：工程选型的核心分界
- 模拟广播 vs 数字广播（IP 网络广播）：适用场景差异
- 一体化主机 vs 模块化堆叠：小项目 vs 大项目的选择逻辑

### 1.3 设计要点与工程约束
- 分区设计原则：按功能区 / 防火分区划分
- 功率冗余设计：扬声器总功率 × 1.3~1.5 余量
- 布线要求：定压喇叭并联、线径与距离核算
- 消防联动接口：干接点 / RS232 / 网络协议

## 二、核心参数与选型

### 2.1 选型公式与关键指标
- 分区功率核算公式：单分区总功率 = Σ(单只喇叭功率 × 数量) × 冗余系数(1.3~1.5)
- 功放容量核算：总功放功率 ≥ 所有分区同时广播的最大可能功率
- 声压级估算：距离每增加一倍，声压级衰减 6dB
- 布线线径选型：按传输距离和功率损耗核算（线径越粗、距离越远，损耗越小）

### 2.2 各部件参数表
- 音源设备（呼叫站、播放器、话筒）
- 前置放大器（输入路数、增益、信噪比）
- 音频矩阵（分区数、输入路数、优先级数、DSP 处理能力）
- 功率放大器（额定功率、定压输出、THD、效率）
- 扬声器（类型、额定功率、灵敏度、声压级、覆盖角）
- 系统控制器（定时任务数、联动接口、监测功能）

### 2.3 工程对接踩坑点
- 定压喇叭极性接反导致声短路
- 分区过多超出功放容量导致削波失真
- 消防联动优先级配置错误导致应急广播无法强切
- 长距离传输线径不足导致末端声压级不够
- 环境噪声未预估导致背景音听不清
- 接地与共模干扰导致电流声

## 三、技术原理

### 3.1 定压传输原理
- 为什么用 100V/70V 定压：降低长距离传输的线损
- 输出变压器的作用：阻抗匹配与电压转换
- 定压 vs 定阻的本质区别

### 3.2 音频信号处理链路
- 前置放大 → A/D 采样 → 数字处理（均衡、压缩、限幅）→ D/A → 功率放大 → 定压输出
- 配图：图2 广播信号处理链路与优先级判定

### 3.3 优先级与强切机制
- 优先级等级划分：消防应急 > 紧急寻呼 > 业务广播 > 背景音
- 强切原理：继电器或数字矩阵的快速通道切换
- 配图：图3 消防应急广播强切流程

### 3.4 IP 网络广播的技术演进
- 数字编码（MP3/AAC/Opus）+ 网络传输（TCP/IP）
- 与模拟广播的对比优势与局限

## 四、产品功能与差异化

### 4.1 核心功能
- 分区广播 / 全区广播 / 选区广播
- 定时广播（作息铃、背景音乐定时播放）
- 消防联动强切（最高优先级自动切换）
- 紧急寻呼（话筒 / 电话 / 终端）
- 背景音播放（多音源可选）

### 4.2 差异化卖点
- 智能分区：根据消防报警区域自动选择对应分区广播
- 状态监测：在线监测喇叭线路、功放工作状态
- 多音源矩阵：任意输入可路由到任意输出分区
- 无人值守：定时任务 + 自动联动 + 远程管理

### 4.3 增强能力
- 与消防系统、门禁系统、视频监控的联动
- 云平台远程管理与多站点统一管控
- 语音清晰度优化（回声抑制、噪声门）

## 五、应用场景

每场景：痛点 → 方案 → 价值

### 5.1 商业综合体 / 商场
- 痛点：面积大、分区多、业态杂，既要背景音又要紧急疏散
- 方案：数字矩阵 + 多分区 + 消防联动，按楼层 / 业态分区
- 价值：提升购物体验 + 应急疏散可靠

### 5.2 学校 / 园区
- 痛点：作息铃、上下课广播、运动会广播、应急演练，场景多
- 方案：定时任务 + 分区寻呼 + 多音源切换
- 价值：教学秩序管理 + 校园安全保障

### 5.3 酒店 / 写字楼
- 痛点：公共区域背景音 + 客房可调节 + 消防应急全覆盖
- 方案：公共区定压 + 客房音量可控 + 消防强切
- 价值：提升入住体验 + 满足消防规范

### 5.4 工业园区 / 厂房
- 痛点：环境噪声大、空间开阔，广播清晰度要求高
- 方案：号角扬声器 + 高功率功放 + 噪声自适应
- 价值：生产调度 + 应急疏散

### 5.5 住宅小区
- 痛点：地下车库 + 园区 + 电梯厅 + 楼道全覆盖
- 方案：分区设计 + 草坪音箱 + 吸顶喇叭组合
- 价值：物业通知 + 背景音乐 + 消防安全

## 六、实际案例与设计方案

每案四段式：需求 → 方案设计 → 配置核算 → 交付价值

### 案例 A：中型商业综合体（5 万㎡）
- 需求：地下 2 层 + 地上 5 层，20+ 分区，消防联动，背景音乐
- 方案设计：数字矩阵主机 + 多台定压功放 + 吸顶/壁挂/号角组合
- 配置核算：分区功率表、功放总容量、线径选型、UPS 容量
- 交付价值：背景音乐提升体验 + 消防联动合规 + 分区灵活管理

### 案例 B：学校园区（100 亩）
- 需求：教学楼 + 操场 + 食堂 + 宿舍，作息铃 + 广播操 + 应急演练
- 方案设计：IP 网络广播 + 分区寻呼站 + 定时任务
- 配置核算：终端数量、带宽估算、功放配置
- 交付价值：教学管理自动化 + 多场景切换 + 维护简便

### 工程落地核算检查清单
- [ ] 分区划分是否与防火分区一致
- [ ] 单分区总功率是否在功放容量内（留 30% 余量）
- [ ] 最远点声压级是否满足要求（≥ 背景噪声 +10dB）
- [ ] 传输线径是否按距离核算（≤ 3dB 损耗）
- [ ] 消防联动接口类型与优先级是否确认
- [ ] UPS / 备用电源是否满足应急广播时长要求（≥ 30 分钟）
- [ ] 接地与防雷措施是否到位

## 七、市场背景与竞争格局

### 7.1 市场规模与驱动
- 公共广播是建筑弱电标配，市场规模稳定增长（行业通用认知）
- 驱动因素：城镇化建设、消防安全法规趋严、商业地产升级
- 趋势：数字化、IP 化、智能化联动

### 7.2 竞争格局
- 国际品牌：博世（Bosch）、霍尼韦尔（Honeywell）、TOA — 高端市场、品牌溢价
- 国内一线：迪士普（DSPPA）、ITC、惠威 — 中端主力、性价比高
- 国内中小品牌：数量众多、价格竞争激烈
- 新进入者：IP 网络广播厂商、音视频一体化厂商

### 7.3 核心竞争要素
- 产品可靠性（尤其是消防联动场景下的稳定性）
- 系统扩展性（分区数量、音源数量）
- 工程服务能力（方案设计、调试、售后）
- 性价比与渠道覆盖

## 八、商业模式与趋势

### 8.1 交付形态
- 设备销售：喇叭、功放、主机等硬件
- 系统集成：方案设计 + 设备供应 + 安装调试
- 运维服务：定期检测、维修保养、升级改造

### 8.2 盈利模式
- 硬件毛利：主设备 + 配件
- 工程利润：安装调试费用
- 运维收入：年度维保合同
- 增值服务：智能化升级、云管理平台

### 8.3 发展趋势
- IP 化：从模拟定压向 IP 网络广播演进
- 智能化：AI 语音交互、智能噪声自适应、自动分区
- 融合化：与消防、安防、楼宇自控深度融合
- 云边协同：云端统一管理 + 边缘节点本地自治
- 高清化：从语音级向高保真音频演进
