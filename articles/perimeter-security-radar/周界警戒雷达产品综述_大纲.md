# 周界警戒雷达产品综述 · 大纲

> 面向工程端 ｜ 周界安防 ｜ 含 14 个原创工程算例 + KaTeX 公式

## 〇 一句话定位
- 主动电子哨兵：毫米波 FMCW 扫描扇区，解算距离/方位/速度，联动球机复核
- 差异化：探测媒介是射频回波，不挑天气与光照

## 一、产品设计方案
1. 三层组成：前端感知 / 信号处理 / 后端联动
2. 两种形态：机械扫描 vs 相控阵电扫
3. 信号处理链路：FMCW→差频 FFT(距离)→Doppler FFT(速度)→CFAR→点迹凝聚→TWS→报警

## 三、技术原理
1. FMCW 测距又测速（二维 FFT）
2. CFAR + TWS 识别真实目标
3. 抗天气不挑光照的物理基础
4. 机械扫描 vs 相控阵
