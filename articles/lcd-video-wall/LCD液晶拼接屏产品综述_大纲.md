## 大纲骨架

### 〇 一句话定位（北极星）

LCD 液晶拼接屏是由多块工业级液晶面板以极窄边拼接而成的大屏显示终端，配合拼接处理器实现整屏显示、任意开窗与信号漫游，是指挥中心、监控室与商业展示场景中最常用的大屏显示方案。

---

### 一、产品设计方案（架构 / 形态 / 设计要点 / 工程约束）

1.1 系统组成全景：拼接单元 + 拼接处理器 + 控制软件 + 安装结构
1.2 拼接单元形态：壁挂式 / 落地机柜式 / 前维护式 / 后维护式
1.3 面板技术演进：从 CCFL 背光到 LED 背光，从 D-Sub 接口到 HDMI 2.0 / DP 1.2
1.4 拼缝设计与物理拼缝 vs 视觉拼缝的差异
1.5 散热与可靠性设计：工业级面板、7×24 小时连续运行、温控与风扇策略
1.6 工程约束：安装空间、承重要求、维护通道、供电与散热

### 二、核心参数与选型【工程端专用】

2.1 选型公式与关键指标
   - 单屏尺寸与整墙尺寸的换算关系
   - 观看距离与最佳尺寸选择（视距 ≈ 屏高 × 1.5~2.5）
   - 分辨率与点距的关系（PPI 计算）
   - 拼接单元数量与矩阵排布（行×列）

2.2 核心部件参数表
   - 面板参数：尺寸、分辨率、亮度、对比度、响应时间、可视角度、色域
   - 拼缝参数：物理拼缝、光学拼缝、拼接方式
   - 接口参数：HDMI / DP / DVI / VGA / SDI / RJ45（网络解码）
   - 可靠性参数：MTBF、使用寿命、工作温度、功耗
   - 拼接处理器参数：输入路数、输出路数、开窗数量、漫游能力、4K 支持

2.3 工程对接踩坑点
   - 拼缝对齐：物理拼接偏差与画面像素对齐的矛盾
   - 色彩一致性：多屏色差校准（亮度均匀性、色准校准）
   - 散热与噪音：多屏密集排布后的热堆积问题
   - 供电规划：单屏功耗 × 数量 × 冗余系数
   - 安装结构：承重核算、平整度调节、前后维护空间预留
   - 信号传输：长距离传输的信号衰减与解决方案（光纤 / 网线延长）

### 三、技术原理

3.1 液晶显示基础：TFT-LCD 面板工作原理（背光 → 液晶层 → 彩色滤光片 → 像素）
3.2 拼接显示原理：多屏拼接的像素映射与画面分割
3.3 拼接处理器工作机制：
   - 信号采集与数字化
   - 画面分割与缩放处理（Scaler）
   - 多窗口叠加与漫游
   - 输出驱动与帧同步
3.4 色彩校准技术：白平衡校准、亮度均匀性校正、3D LUT 校色
3.5 冗余与可靠性：双电源备份、信号热备份、环通输出
3.6 前维护 vs 后维护的机械结构原理

### 四、产品功能与差异化

4.1 核心显示功能
   - 整屏显示：单信号全屏拼接显示
   - 分屏显示：多路信号同时显示（1/4/9/16 分屏等）
   - 任意开窗：可拖拽、可缩放的活动窗口
   - 信号漫游：窗口跨屏移动与缩放
   - 画面叠加：画中画（PIP）、画外画（POP）
   - 场景轮巡：多场景自动切换轮巡

4.2 增强功能
   - 4K 超高清输入支持
   - HDR 高动态范围显示
   - 网络解码直显（支持 ONVIF / RTSP 网络摄像头直接解码上墙）
   - 多屏拼接控制软件（C/S 或 B/S 架构）
   - 场景预设与一键切换
   - 远程管理与状态监控

4.3 差异化维度
   - 拼缝宽度（3.5mm / 1.7mm / 0.88mm / 0mm 无接缝）
   - 面板类型（IPS / VA / PLS）
   - 亮度等级（普通 500cd/m² / 高亮 700~1000cd/m²）
   - 拼接处理器架构（嵌入式 / X86 / FPGA）
   - 维护方式（前维护 / 后维护）

### 五、应用场景

5.1 指挥调度中心
   - 痛点：多路监控信号、数据大屏需同时呈现，要求 7×24 稳定运行
   - 方案：大屏拼接 + 多窗口漫游 + 场景预设 + 双机热备
   - 价值：一屏掌控全局，提升指挥决策效率

5.2 安防监控室
   - 痛点：上百路监控画面需同时监看，重点画面需放大查看
   - 方案：视频解码器 + 拼接屏 + 矩阵切换 + 报警联动弹窗
   - 价值：提升监控效率，异常事件快速响应

5.3 商业展示与零售
   - 痛点：品牌展示需要大尺寸、高清晰度、视觉冲击力强
   - 方案：超窄边拼接 + 4K 播放盒 + 互动触控（可选）
   - 价值：吸引客流，提升品牌形象与信息传达效果

5.4 会议室与报告厅
   - 痛点：本地演示 + 远程视频会议 + 多源信号切换
   - 方案：拼接大屏 + 视频会议终端 + 中控系统集成
   - 价值：提升会议体验，支持多形式内容展示

### 六、实际案例与设计方案【工程端建议保留】

#### 案例 A：某城市应急指挥中心大屏系统

**需求**：
- 显示面积：约 8m 宽 × 3m 高
- 信号源：监控视频（64 路）、GIS 地图、数据可视化、视频会议
- 使用要求：7×24 小时连续运行，支持多窗口漫游与场景切换
- 安装方式：落地机柜式，后维护

**方案设计**：
- 拼接单元：55 寸 1.7mm 拼缝，3×6 排布（3 行 6 列，共 18 块屏）
- 整墙尺寸：宽约 7.3m × 高约 2.06m
- 拼接处理器：18 路输出，支持 16 路同时开窗
- 安装结构：定制落地机柜，含散热与走线槽

**配置核算**：
- 屏体数量：3×6 = 18 台
- 拼接处理器：1 台（18 输出 × 32 输入）
- 控制软件：1 套
- 安装结构：1 套（定制机柜）
- 供电：单屏约 180W × 18 = 3.24kW，加处理器约 4kW 总功耗，建议 6kW 供电容量
- 散热：按 300W/m² 估算，约需 5~6kW 制冷量

**交付价值**：
- 整墙分辨率达 5760×3240（超 4K），画面细腻
- 1.7mm 窄拼缝，整屏视觉连贯性好
- 支持 16 路信号同时开窗漫游，满足多源信息并发展示需求
- 7×24 工业级面板，满足指挥中心全天候运行要求

#### 案例 B：某企业监控中心

**需求**：
- 显示面积：约 4.8m 宽 × 1.8m 高
- 信号源：32 路网络摄像头 + 1 路数据大屏
- 预算有限，要求性价比高
- 安装方式：壁挂式

**方案设计**：
- 拼接单元：49 寸 3.5mm 拼缝，2×4 排布（2 行 4 列，共 8 块屏）
- 整墙尺寸：宽约 4.78m × 高约 1.35m
- 解码方案：网络解码矩阵（支持 32 路 1080P 解码）
- 安装结构：壁挂支架，前维护设计

**配置核算**：
- 屏体数量：2×4 = 8 台
- 网络解码矩阵：1 台（8 屏输出，32 路解码）
- 壁挂支架：1 套
- 供电：单屏约 140W × 8 = 1.12kW，加解码器约 1.5kW 总功耗

**交付价值**：
- 性价比高，满足中小型监控中心需求
- 前维护设计，节省后部空间
- 网络直连解码，无需额外视频分配器

**工程落地核算检查清单**：
- [ ] 观看距离与屏体尺寸匹配（视距 ≈ 屏高 × 1.5~2.5）
- [ ] 安装面承重满足要求（壁挂需确认墙体结构）
- [ ] 维护空间预留（后维护需 ≥ 600mm 通道）
- [ ] 供电容量充足（按总功耗 × 1.3 冗余系数）
- [ ] 散热条件满足（环境温度 ≤ 35℃，通风良好）
- [ ] 信号传输距离在规格范围内（HDMI ≤ 15m，光纤延长更远）
- [ ] 拼缝对齐与色彩校准方案已落实
- [ ] 接地与防雷措施到位

### 七、市场背景与竞争格局

7.1 行业发展背景
   - 智慧城市建设推动指挥中心、监控室大屏需求增长
   - 商业显示市场持续扩大，零售、企业、展览展示需求旺盛
   - 超高清化趋势：从 1080P 向 4K、8K 演进
   - 窄边化趋势：拼缝从 5.3mm → 3.5mm → 1.7mm → 0.88mm 不断收窄

7.2 竞争格局
   - 面板厂商：三星、LG、京东方（BOE）、华星光电等提供核心面板
   - 整机品牌：海康威视、大华、TCL、创维、洲明、利亚德等
   - 拼接处理器厂商：纯硬件嵌入式（快捷、CREATOR）、X86 架构（威创、GQY）
   - 价格带分布：从几千元/屏到几万元/屏不等，取决于面板尺寸、拼缝、亮度

7.3 与 LED 小间距的竞争关系
   - LCD 优势：色彩准确、单价低、近距离观看效果好、维护方便
   - LED 优势：无缝拼接、亮度更高、尺寸更灵活、户外可用
   - 适用场景差异：室内近距离观看选 LCD，大空间远距离观看或户外选 LED

### 八、商业模式与趋势

8.1 常见交付形态
   - 产品销售：屏体 + 处理器 + 安装结构，按套报价
   - 系统集成：含设计、供货、安装、调试、培训的总包服务
   - 租赁服务：展会、活动等短期场景的租赁模式

8.2 盈利模式
   - 硬件毛利：屏体、处理器、配件的销售利润
   - 工程服务：安装调试、系统集成服务费用
   - 维保服务：延保、年度维护、校准服务
   - 软件增值：拼接控制软件高级功能、远程运维平台

8.3 技术发展趋势
   - 更窄拼缝：向 0.88mm 及以下推进，接近无缝视觉效果
   - Mini/Micro LED 背光：提升对比度与色彩表现
   - 一体化与标准化：出厂预装结构，降低现场安装难度
   - 智能化：AI 画质增强、自动色彩校准、远程智能运维
   - 电容触控：支持大屏触控交互（教育、会议场景）
